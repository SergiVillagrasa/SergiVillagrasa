I am a Telecommunications Engineering student at Universitat Pompeu Fabra (UPF). I am building my path into cybersecurity through hands-on work in web security, network defence, and the security challenges introduced by large language models.

My current practice includes PortSwigger Web Security Academy and Hack The Box labs, with a particular interest in SQL injection and prompt injection. My goal is to turn that practice into clear, professional security reports and, as my experience grows, contribute useful work to open-source security projects.

## Current focus

- Building practical offensive-security skills through structured labs and reproducible exercises.
- Learning to document findings, impact, evidence, and remediation in professional security reports.
- Exploring web application security with Burp Suite and studying SQL alongside injection techniques.
- Investigating prompt injection and the security boundaries of LLM-enabled systems.
- Working primarily on Fedora and strengthening my Linux, networking, and scripting fundamentals.

## Featured projects

- **[NetworkArchitectureP202-23](https://github.com/servillagrasa/NetworkArchitectureP202-23)** — A collaborative, Suricata-inspired IDS/IPS project that combines Mininet network emulation, Scapy packet analysis, and a Multi-Layer Perceptron to detect SYN flood and ARP spoofing attacks. The system can respond with `iptables` rules and connect network-security decisions to Kubernetes auto-scaling.
- **[MarketPulse UK — Damm Hackathon](https://github.com/servillagrasa/HackathonDamm)** — A team-built sales forecasting and decision-support product developed under hackathon time constraints. It combines a Python forecasting pipeline, FastAPI backend, and interactive TypeScript dashboard while keeping confidential source data outside the repository.
