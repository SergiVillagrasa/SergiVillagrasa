## Featured projects

### [Swiss Transport Assistant — Swiss AI Weeks](https://github.com/SergiVillagrasa/SwissAI-Hacks26)

A team-built AI travel assistant for Swiss rail journeys and Zurich Airport connections. Combines a Python MCP server and FastAPI agent backend with a React interface, streaming responses, interactive route maps, and voice input/output.

**Stack:** Python · FastAPI · MCP · React · TypeScript · Mapbox · OJP 2.0

### [Engineering Hub](https://engineeringhub.cat/)

Contributing to the association's web platform, including membership applications, CV uploads, authentication, and administration workflows. The work spans frontend interfaces, API contracts, database migrations, and deployment.

**Stack:** TypeScript · Next.js · React · Express · PostgreSQL · Drizzle

### WatchAgent — HackBarna26

A collaborative hackathon project for movie discovery across TV, voice, and Telegram. Combines a Mastra recommendation workflow with a React interface, live execution visualisation, and QR-based group voting.

**Stack:** TypeScript · React · Mastra · React Flow · Express  
*Private repository.*

### [NetworkArchitectureP202-23](https://github.com/servillagrasa/NetworkArchitectureP202-23)

A collaborative IDS/IPS project combining Mininet network emulation, Scapy packet analysis, and a Multi-Layer Perceptron to detect SYN flood and ARP spoofing attacks, with responses through `iptables`.

### [MarketPulse UK — Damm Hackathon](https://github.com/servillagrasa/HackathonDamm)

A team-built sales forecasting and decision-support product, combining a Python forecasting pipeline, FastAPI backend, and interactive TypeScript dashboard.
