I am a Telecommunications Engineering student at **Universitat Pompeu Fabra (UPF)** in Barcelona. I build web applications and AI-powered tools, with a particular interest in how agents interact with real data, external services, and the people using them.

Alongside my studies, I am **Co-President of Engineering Hub**, a student technology community in Barcelona. I help organise hackathons, technical sessions, company visits, and community events, and contribute to the development of our membership platform.

## Current focus

- Building full-stack applications with TypeScript, React, Next.js, and Python.
- Developing AI agents and MCP integrations backed by real data sources.
- Exploring agent workflow visualisation and interfaces that make tool execution easier to follow.
- Turning hackathon prototypes into documented, testable projects.
- Strengthening my cybersecurity foundations through PortSwigger labs, Burp Suite, and hands-on web security practice.

## Featured projects

- **[Hacktoberfest “Touch Grass”](https://github.com/SergiVillagrasa/Hacktoberfest-W1)** — A real-world multiplayer photo scavenger hunt for 2–6 friends, with AI-generated voice and visual clues, vision-based matching evidence, and live room updates. Built with Next.js, Express, Mastra, ElevenLabs, fal, and PostgreSQL. [Play the demo](https://sergi-villagrasa.tech/projects/snaphunt).
- **[Swiss Transport Assistant — Swiss AI Weeks](https://github.com/SergiVillagrasa/SwissAI-Hacks26)** — A team-built AI travel assistant for Swiss rail journeys and Zurich Airport connections. Combines a Python MCP server and FastAPI agent backend with a React interface, streaming responses, interactive route maps, and voice input/output.
- **[Engineering Hub](https://engineeringhub.cat/)** — Contributing to the association's membership platform, including applications, CV uploads, authentication, and administration workflows. Built with TypeScript, Next.js, Express, PostgreSQL, and Drizzle.
- **WatchAgent — HackBarna26** — A collaborative movie-discovery project across TV, voice, and Telegram, combining a Mastra workflow, React interface, live execution visualisation, and QR-based group voting. *Private repository.*
- **[NetworkArchitectureP202-23](https://github.com/servillagrasa/NetworkArchitectureP202-23)** — A collaborative, Suricata-inspired IDS/IPS project that combines Mininet network emulation, Scapy packet analysis, and a Multi-Layer Perceptron to detect SYN flood and ARP spoofing attacks. The system can respond with `iptables` rules and connect network-security decisions to Kubernetes auto-scaling.
- **[MarketPulse UK — Damm Hackathon](https://github.com/servillagrasa/HackathonDamm)** — A team-built sales forecasting and decision-support product developed under hackathon time constraints. It combines a Python forecasting pipeline, FastAPI backend, and interactive TypeScript dashboard while keeping confidential source data outside the repository.
